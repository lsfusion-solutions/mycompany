# Contributing to MyCompany

Thanks for your interest in improving MyCompany!

## Bugs and feature requests

Open a [GitHub issue](https://github.com/lsfusion-solutions/mycompany/issues). Please include the version you are running, steps to reproduce and, for UI problems, a screenshot. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Questions and discussion

Ask in [Slack](https://join.slack.com/t/lsfusion/shared_invite/zt-2klihpl2q-h6ol~nDRPky~O1uHC14Dwg) or [Telegram](https://t.me/lsfusion_official).

## Code contributions

MyCompany is written in [lsFusion](https://lsfusion.org). The [development guide](https://mycompany-docs.lsfusion.org/administration/development/) explains how to set up a development environment.

Fork the repository, make your changes and open a pull request against `master`. For larger changes, please discuss the idea in an issue first.

Before opening a PR:

- run the application locally with your change and smoke-test the affected forms;
- keep the change focused — one topic per pull request;
- reference the related issue in the PR description and explain the motivation;
- for UI changes, attach a screenshot.

If you are customizing MyCompany for your own company rather than contributing to the product, prefer separate extension modules over changing product code — the development guide covers this approach.
